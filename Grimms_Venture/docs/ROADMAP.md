# Roadmap

## Fase 0 - Base (esta entrega)
- [x] Estrutura do projeto, loop, telas, input gamepad/teclado
- [x] Lutador com voo, dash, combo de 3, golpe forte, ki blast, guarda, carga de ki
- [x] Versus 1v1 local, câmera compartilhada e tela dividida
- [x] HUD, intro/KO/rematch/pausa, hit-stop, shake, partículas, arena procedural

## Fase 1 - Protótipo jogável (fazer próximo)
- [ ] Rodar, ajustar o "feel" (velocidades, hitstun, câmera) com playtest
- [ ] Rounds (melhor de 3) e timer
- [ ] Sistema de animação esquelética com blending (decisão: glTF + SharpGLTF ou skinning próprio)
- [ ] Primeiro personagem com modelo/animações reais
- [ ] Áudio básico (SFX de hit, música) via SoundEffect/Song

## Fase 2 - Profundidade
- [ ] Golpes especiais com câmera própria, super ataque, transformação
- [ ] Mais personagens e seleção de personagem
- [ ] Mais arenas, destruição simples
- [ ] IA para treino/CPU (máquina de estados)
- [ ] Menu de opções (rebind de controles, vídeo, áudio)

## Fase 3 - Produto
- [ ] Modo história/torneio
- [ ] Content Pipeline (MGCB) para assets finais
- [ ] Credenciamento e port de console
- [ ] Polimento, balanceamento, otimização para tela dividida
